# Code of Conduct

Project contributors are expected to make participation respectful, safe, and
welcoming. Harassment, discrimination, threats, doxxing, and sustained
disruption are not acceptable in project spaces.

Report conduct concerns privately to the maintainers through the repository's
security contact. Maintainers may edit or remove contributions and restrict
participation when necessary to protect the community. Good-faith technical
disagreement is welcome; personal attacks are not.
