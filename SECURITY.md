# Security policy

## Supported versions

Security fixes are provided for the latest published pre-release until a
stable support policy is announced.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory form for `rickphp/laravel-rick` and include affected versions,
impact, reproduction steps, and any proposed mitigation. Maintainers aim to
acknowledge a complete report within five business days.

Never include production credentials, tenant data, provider prompts, or raw
encrypted payloads in a report. Rotate any credential that may have been
exposed during testing.
